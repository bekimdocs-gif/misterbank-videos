# Mister Bank — atelier vidéo TikTok

Dépôt public utilisé pour fabriquer et héberger les vidéos TikTok de **Mister Bank** (directeur de banque, vulgarisation finance).
Les vidéos sont publiées via Metricool (marque `8028968`, compte TikTok MisterBank) à **12 h et 18 h** chaque jour.

- `AUTOMATISATION.md` : procédure quotidienne suivie par la tâche programmée.
- `CHARTE.md` : identité, structure des vidéos, règles à respecter.
- `FICHE.md` : format des fiches JSON qui décrivent une vidéo.
- `HISTORIQUE.md` : vidéos publiées / programmées (à mettre à jour à chaque vidéo).
- `IDEES.md` : réserve de sujets.
- `EXPERTISE.md` : connaissances transmises par Mister Bank (à utiliser en priorité).
- `atelier/` : générateur (`make_video.py fiche.json sortie.mp4`).
- `fiches/` : fiches des vidéos. `videos/` : vidéos finales (lien public raw GitHub donné à Metricool).

Ne jamais mettre dans ce dépôt de photo ou de donnée personnelle.
